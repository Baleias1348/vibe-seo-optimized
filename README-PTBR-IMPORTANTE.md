# ATENÇÃO: Diretriz obrigatória para desenvolvimento do site

Este projeto é voltado para turistas brasileiros que viajam ao Chile. Portanto, **o idioma padrão do site é sempre o Português do Brasil**.

## Regras obrigatórias:
- **Todas as rotas, nomes de componentes, nomes de arquivos de imagens, metadados, informações de SEO, etc. devem estar em português brasileiro por padrão.**
- O uso de espanhol só é permitido em casos excepcionais explicitamente autorizados pelo responsável do projeto.
- Se encontrar nomes, textos ou arquivos em espanhol, considere que são legados ou exemplos, mas a versão final deve ser sempre em português brasileiro.
- Antes de criar novas páginas, componentes ou assets, confirme que o nome está em português brasileiro e é SEO friendly.
- Em caso de dúvida, consulte o responsável pelo projeto.

## Exemplo de nomes corretos
- `/pesquisa-de-voo-por-rota` (correto)
- `banne-culinaria-chilena.png` (correto)
- `HomeBoxModel` → idealmente `CaixaHomeModel` (mas mantenha nomes legados se já amplamente usados)
